# Miqueas Machín Studio — propuesta web

Propuesta de rediseño para **Miqueas Machín Studio**, peluquería masculina y visagismo en Las Palmas de Gran Canaria.

- Web estática en un solo `index.html` (GSAP + ScrollTrigger + Lenis desde CDN).
- Fotos reales en `img/`, sacadas de miqueasmachinstudio.com y de Instagram @miqueasmachin.
- Estilo minimalista: papel cálido, tinta negra, fotos en B/N.
